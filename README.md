# LyokhaVR

Университетская VR-игра на Unity: поиск физических предметов в контейнерах, инвентарь и продажа находок, киоск с едой и батарейками, голод, смена суток, уличные фонари, сирены и укрытия. После задержания — отдельная сцена автозака.

**Версия Unity: 6000.6.7f1.** Поддерживаются обычное управление мышью/клавиатурой и официальный XR Interaction Simulator. Подготовлен пункт запуска Meta Quest 3 через Windows PC/OpenXR; аппаратная проверка шлема ещё предстоит.

## Скачать и открыть

1. На этой странице нажать **Code → Download ZIP** и полностью распаковать архив.
2. В Unity Hub нажать **Add project from disk** и выбрать распакованную папку, внутри которой находятся `Assets`, `Packages` и `ProjectSettings`.
3. Открыть проект в Unity **6000.6.7f1** и дождаться импорта и загрузки пакетов. При первом запуске нужен интернет.
4. В верхнем меню Unity выбрать **LyokhaVR → Launch**:
   - **Desktop (keyboard and mouse)** — обычная игра;
   - **VR Simulator** — симулятор шлема и контроллеров;
   - **Quest via Windows PC (OpenXR)** — Quest 3 через Meta Quest Link на Windows.

Между режимами остановить Play. Для настоящего Quest на Windows сначала запустить Link-сессию и выбрать Meta Link активным OpenXR runtime. [Подробная инструкция](Documentation/TRANSFER_TO_VR_PC.md).

## Скачать через Git

Для крупных моделей используется Git LFS. Установить Git LFS до клонирования:

```sh
git lfs install
git clone https://github.com/40404040404040l/LyokhaVR.git
```

Если репозиторий уже склонирован без LFS, выполнить в нём `git lfs pull`. Большие модели должны быть настоящими бинарными файлами, а не короткими текстовыми указателями LFS.

## Управление

- Desktop: Enter/щелчок — включить управление; WASD, Shift, мышь; ЛКМ — взять/отпустить; E — в карман; I/Tab — инвентарь; F — фонарик; B — киоск; Esc — курсор.
- Quest: левый стик — ходьба; grip — близкий захват; trigger удерживаемой находки — в карман; левая основная кнопка — инвентарь; правая основная — фонарик. В меню — луч + trigger.
- Симулятор: Tab — выбрать устройство; WASD/QE — двигать его; G — grip; T — trigger; IJKL — стик.

## Состав проекта

Рабочие сцены, скрипты, модели, текстуры, шрифты, звук, настройки и версии пакетов лежат обычными папками. `Library`, `Temp`, логи и локальные сборки исключены.
