## Реализация

Созданы CourtyardDesktop/CourtyardVR на основе проверенных сцен физического контейнера. Существующая локация, движение, близкий захват XRI, физические тела, инвентарь и GameRules переиспользованы. Старые сцены сохранены.

- Добавлены три копии работающего контейнера и доступные напольные находки. Всего 17 полезных предметов, включая три аптечки и две батарейки. Торговые типы перемешиваются при старте, без зон ценности. Они существуют в сцене до подбора. RNG-выдачи по кнопке поиска нет.
- Инвентарь ограничен шестью ячейками, крупный металл занимает две. «Достать из кармана» возвращает исходное физическое тело с тем же ID в мир.
- uGUI-панель: список вещей → выбор → отображаемая цена → продажа одного выбранного предмета. На компьютере обычный UI-модуль Input System, в VR — мировой Canvas с TrackedDeviceGraphicRaycaster и XRUIInputModule. Мир виден вокруг панели, пауза игрового времени не включается. Авторские мировые текстовые надписи временно скрываются при открытии, потому что их исходный overlay-материал мог рисоваться поверх панели.
- Условие нахождения у стойки проверяется и кнопкой, и игровой сессией. После продажи ID исчезает из инвентаря, повторное начисление исключено. Цена показывается до продажи согласно последнему описанию пользователя.
- Аптечка восстанавливает полное здоровье и сохраняется при полном HP; батарейка пополняет заряд. Используются существующие правила Use. Новые источники повреждений в этот набор не добавлялись.
- Реальный Spot Light следует направлению взгляда. Управляется F / основной кнопкой правого контроллера / кнопкой меню. Включённый свет расходует заряд в реальном времени.
- Патруль использует существующую сетку проходимости и реальные коллайдеры двора: обнаружение в прямой видимости, движение по пути, погоня, отрыв по расстоянию. Захват удерживает до 35 рублей, сохраняет инвентарь и сессию, возвращает игрока к старту и даёт время от повторного задержания. Старый сценарий конфискации/полицейской концовки в этих сценах не вызывается.
