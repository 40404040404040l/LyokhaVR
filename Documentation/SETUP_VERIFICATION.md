# Подготовка и проверки — 7 ноября 2026

- Unity 6000.6.7f1 (arm64), активная лицензия Unity Personal.
- Unity CLI 1.0.0-beta.17; Pipeline 0.10.0-exp.1, управление живым редактором проверено.
- URP 17.6.0, Input System 1.20.1, uGUI 2.6.0, Test Framework 1.8.0.
- XR Interaction Toolkit 3.7.0, XR Management 4.7.0, OpenXR 1.19.0.
- Официальные Starter Assets и XR Interaction Simulator, ресурсы TextMesh Pro, слой Interaction Layer 31 = Teleport.
- Сцены `Preparation.unity` и `XRPreparation.unity` в `Assets/_Project/Scenes`.
- Исходная локация скопирована, оригинальный FBX за пределами проекта сохранён. 45 мешей, 79 552 треугольника, 25 материалов. Из FBX извлечены встроенные изображения; 44 распознаны Unity как текстуры.
- Локальный Git; сборки, Library, Temp, журналы и настройки пользователя исключены из истории.

## Что действительно проверено
1. В Play Mode счётчик кадров меняется. Проверка выполнялась серверной командой ожидания, а не только снимком экрана.
2. Настоящие системные клавиши через Computer Use: Enter захватил курсор, E вызвала взаимодействие (счётчик 0 → 1), D переместила игрока, R вернула на старт, Escape освободила курсор.
3. Персонаж опирается на землю; гравитация продолжает работать при освобождённом курсоре.
4. Подготовительная сцена: нет ошибок и предупреждений в Console после последнего запуска.
5. XR-сцена запускается, кадры обновляются. Симулятор создаёт `XRSimulatedHMD` и два `XRSimulatedController`. Присутствует `XRGrabInteractable` для дальнейшей проверки захвата.
6. В XR-запуске нет ошибок; есть одно предупреждение об отсутствии поддержки вибрации виртуальным контроллером. Реальную вибрацию без устройства проверить нельзя.
7. Собрана и запущена отдельная macOS-версия `Build/LyokhaVR-Preparation.app` (187 191 477 байт). Сборка успешна, ошибок 0. Unity автоматически подготовил коллизии и выдал предупреждение о необходимости включить предварительный расчёт коллизий в настройках импорта для совместимости с будущими версиями.
8. В самостоятельном приложении проверены Enter, E и Escape: изображение отображается, запись `[Preparation] Interaction confirmed: 1` подтверждена в Player.log. Реальный запуск сохранён на `Verification/standalone-verified.png`. Player.log также содержит предупреждения URP о вырезанных неиспользуемых постэффектах Depth of Field/Panini; эти эффекты в нашем профиле не используются.

Отчёты: `Verification/desktop-native-input.json`, `desktop-reset.json`, `gravity-with-free-cursor.json`, `xr-simulator.json`, `build-summary.json`, `standalone-smoke-test.json`. Изображения: `preparation-final.png`, `xr-simulator.png`, `courtyard-overview.png`, `standalone-verified.png`.

Программная имитация клавиатуры/мыши в редакторе не дала надёжной доставки событий. Её не засчитывали как успешный тест; вместо неё проверили настоящие системные клавиши. Диагностика оставлена в исключённой из Git папке Logs.

## Пока не проверено
- Захват и полноценное прохождение VR-сценария контроллерами симулятора.
- Реальный VR-шлем, его целевая платформа, производительность, масштаб и комфорт.
- Основные механики игры: инвентарь, экономика, здоровье, полиция, время суток, мусоровоз, кошелёк, концовки и игровой перезапуск. Здесь пока проверен только подготовительный контроллер и тестовый куб.
- Локация требует доработки материалов/UV и игровых проходов; исходный FBX пока используется как есть.
- Доставка уведомлений на телефон и режим автоматического рассмотрения разрешений пока не подтверждены пользователем.

## Проверка удалённой работы
- Пользователь подтвердил, что видит чат с телефона.
- Запрос проверки подключения к Unity принят; редактор доступен на порту 7800, PID 32096.
- Принят запрос запуска `caffeinate -i -w 32096`. Через `pmset -g assertions` подтверждено предотвращение автоматического сна до завершения текущего процесса редактора. После перезапуска Unity эту временную защиту нужно запустить заново. Mac следует оставить на питании с открытой крышкой.
- Источник принятого разрешения (телефон или компьютер) отдельно технически не проверялся.

## Следующие действия пользователя
1. Чат уже виден пользователю с телефона. Для управления хостом при необходимости завершить сопряжение в Settings → Connections → Control this Mac → Set up / Add под тем же аккаунтом и workspace.
2. Разрешить уведомления на телефоне; их доставка пока не проверена.
3. Временное предотвращение автоматического сна включено для текущего Unity Editor; оставить Mac на питании, с открытой крышкой и работающим приложением.
4. При наличии выбрать Approve for me / Auto-review в меню разрешений чата. Этот режим не отменяет все запросы и не даёт агенту права самовольно принимать договоры.
5. После проверки подключения явно запустить `/goal` с критериями готовности игры. Длительная цель пока не запускалась.
