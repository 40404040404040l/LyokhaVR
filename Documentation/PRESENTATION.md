# Интерфейс и звук прототипа

`GameHud` создаёт uGUI Canvas и TMP-текст при инициализации; игровое состояние поступает только через `HudSnapshot`. Экранный вариант использует CanvasScaler 1920×1080 с балансом ширины и высоты. VR-вариант — world-space Canvas шириной 1,92 м на расстоянии 2,35 м, плавно следующий за взглядом. Шрифт Liberation Sans скопирован из установленных TMP Essentials в Resources; динамический SDF включает кириллицу. В старой версии Liberation Sans нет знака рубля, поэтому HUD отображает его как «руб.». Русский текст не зависит от наличия системных шрифтов на компьютере игрока.

HUD показывает цель, деньги/время через строку stats, здоровье, батарею, сообщение, прицел, подсказку взаимодействия и шесть ячеек. Есть стартовый экран, пауза, помощь, решения, итог с перезапуском. Интерфейс передаёт команды через `CommandRequested`: `start`, `resume`, `restart`, `pause`, `close`, `help`, `inventory`, `use`, `drop`, `select:0` … `select:5`, `decision:0` … `decision:2`. Игровые правила остаются у GameSession. На VR-кнопках есть TrackedDeviceGraphicRaycaster и физические коллайдеры с WorldAction для общего луча взаимодействия.

`GameAudio` синтезирует оригинальные короткие звуки в памяти. `PlayCue` — интерфейсные/локальные события, `PlayWorldCue` — пространственный звук двора, `SetNight` меняет тихий фон. Полиция — быстрые высокие чередующиеся тоны; скорая — плавная восходящая/нисходящая сирена; пожарная — медленные низкие двойные тоны; мусоровоз — двигатель, металлический стук и сигнал заднего хода; разгрузка — отдельные низкие удары и редкий высокий сигнал. Дополнительные сигналы: search, collect, sale, hurt, heal, flashlight, rat, warning, error, ending. Громкость ограничена; шум не использует внешний контент или записи служб.

Компиляцию, внешний вид и фактическое воспроизведение проверяет общий сценарий интеграции проекта; наличие этого файла само по себе не подтверждает плейтест. Реальный VR-шлем пока неизвестен, поэтому удобство чтения на устройстве остаётся отдельной проверкой.
