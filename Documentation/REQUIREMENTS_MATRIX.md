# Матрица проверки требований

Промежуточная матрица. Пустое или ожидающее подтверждения свидетельство не означает готовность.

| Требование | Реализация | Свидетельство на текущем этапе |
|---|---|---|
| Клавиатура и мышь | DesktopMotor, CharacterController, общий луч WorldAction | Настоящие Enter/W/E; короткий маршрут `playthrough-smoke.json` |
| VR, руки и перемещение | Official XR Origin, VRWorldAction, world-space HUD | Сцена создана; полноценная симуляция ожидает проверки |
| Осмотр и физическое перемещение находок | Rigidbody; ЛКМ/ПКМ и XRGrabInteractable | Подбор подтверждён; перенос в руке ещё проверить |
| 6 ячеек, крупная вещь занимает 2 | GameRules/GameConfig | NUnit; физическое переполнение ещё проверить |
| 1–3 находки, разные зоны, истощение точки | GameRules.Search, восемь точек | NUnit + короткий маршрут |
| Раздельная продажа, изучение цен | Три типа приёма, KnownPrices | NUnit + продажа 30 руб. в сцене |
| 250 руб. и покупка еды | Отдельный магазин и Food ending | NUnit + `playthrough-food.json`: 416,35 м, покупка за 250 руб. |
| Здоровье, стекло, шприцы, крысы, аптечки | GameRules, WorldHazard | NUnit; сценические проверки ожидаются |
| Полиция: звук, видимость, погоня, потеря следа | PatrolAgent, реальная сетка коллизий | Наблюдалось задержание; воспроизводимые проверки ожидаются |
| Надёжное и сомнительное укрытие | WorldPoint, состояние укрытия, вероятностное обнаружение | Ожидает сценической проверки |
| Время действиями, день/ночь | GameRules + свет сцены | NUnit; визуальная смена ещё проверить |
| Фонарь, расход и замена батареи | Light + TickFlashlight/Use | NUnit; сценическая проверка ожидается |
| Мусоровоз очищает точки и предупреждает | Планировщик GameSession, TruckVisual, звук | Наблюдалась очистка; ветки выхода/гибели ещё проверить |
| Пять различимых звуков событий | Оригинальные синтезированные клипы и подписи | Код создан; данные и воспроизведение ещё проверить |
| Кошелёк: оставить деньги / вернуть | Физическая находка, выбор, разговор с владельцем | NUnit + `playthrough-job.json`, `playthrough-wallet_keep.json` |
| Еда, работа, полиция, контейнер, здоровье | Ending + экраны финала | Все пять прошли: отдельные `Verification/playthrough-*.json` и `ending-*.png` |
| Перезапуск | Сброс правил, физического мира, патруля и таймеров | NUnit + начало короткого маршрута; после каждого финала ещё проверить |
| Локация и последние правки | Копия FBX, UV пола, фасады, машины, временный мусор | Арка поднята; физический луч подтвердил потолок 4,017 м |
| macOS-приложение | Две сцены в Build Settings, desktop первая | Подготовительная сборка устарела; игровая сборка ещё не создана |
| Отчёт и инструкции | Документация проекта, JSON/PNG проверок | Обновляется по фактическим результатам |

Реальный шлем и целевая VR-платформа неизвестны; проверки на устройстве перечисляются как отдельное ограничение, не как пройденные тесты.
