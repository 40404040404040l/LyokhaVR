# Один контейнер: состояние на 8 ноября 2026

**VR-прогон в официальном XR Interaction Simulator и полный клавиатурный прогон прошли.** После сообщения пользователя о неработающем управлении исправлены вход по щелчку и доступность предметов мышью. Создано и запущено актуальное приложение `Build/LyokhaVR-Container.app`. Настоящий шлем не подключён и не проверен.

## Что реализовано

В существующем дворе создан один открытый контейнер с пятью неподвижными коллайдерами и девятью отдельными динамическими предметами. Металл заранее сохранён на дне сцены под двумя коробками. Модели временные: коробки, капсула-бутылка, цилиндр-банка, пластиковый шар и металлическая пластина.

Обе руки используют близкий захват XRI, динамическое физическое перемещение и бросок со скоростью руки. Дальний захват в этих сценах отключён. Одновременный захват двумя руками позволяет отпустить первую руку и оставить тот же объект во второй; масштабирование двумя руками отключено. Предметы сталкиваются с контейнером, друг с другом и двором.

Сцены не запускают старый GameSession и его `Search` с задержкой и RNG. Старые полные игровые сцены сохранены как предыдущая работа; в Build Settings включены только две сцены этого контейнера.

## Правило учёта

Используется существующий GameRules и GameConfig. Находка — `Scrap`, одна ячейка, цена продажи по конфигу 40 ₽. В начале создаётся только её уникальная запись в GroundItems, физический объект уже находится в сцене. Сам захват ничего не начисляет.

Для помещения в инвентарь нужно держать металл и поднять его целиком выше бортика. В VR — trigger удерживающей руки, на компьютере — E. Это прямой учёт уже извлечённого предмета, без таймера и случайной награды. Обычный мусор не учитывается. Повторный ввод, повторный TryStore и повторный PickUp того же ID не дают второй предмет.

За подбор денег нет: после успешного VR-прогона инвентарь 1/6, деньги 0 ₽. Деньги остаются за существующим правилом продажи. Торговая точка в этот ограниченный пример не добавлена.

Источник: `Verification/PhysicalRummage/vr-report.json`, статус `passed`, 2223 реально прошедших кадра сцены; ввод подан через официальные симулируемые HMD и контроллеры, с обычной обработкой Input System / XRI. Тест не вызывал SelectEnter и не перемещал тестируемые предметы через Transform.

- Девять тел устойчиво остаются в контейнере; скорость каждого после укладки меньше 0,06 м/с. Находка до начала скрыта, инвентарь пуст.
- Подход к контейнеру левым стиком, захват и отпускание каждой рукой.
- Подъём и вращение коробки для осмотра.
- Захват одной коробки двумя руками, отпускание первой руки, удержание второй. Количество объектов остаётся девять.
- Бросок левой рукой: измеренная скорость после отпускания `(-7.64, 1.25, 0.00)` м/с. После отпускания коробка продолжает полёт, сталкивается с двором и останавливается.
- Верхняя и нижняя коробки убраны руками; открывается тот же металл, который был на дне до начала.
- Trigger внутри контейнера не убирает находку в карман. После физического извлечения левый trigger учитывает исходный ID `item-1` ровно один раз.

Первый VR-прогон остановился на слишком коротком ожидании укладки катящегося шара. Ожидание исправлено на ограниченное ожидание физического успокоения; следующий полный прогон прошёл.

## Исправление клавиатурного режима

Источник: `Verification/PhysicalRummage/desktop-report.json`, статус `passed`, 1056 прошедших кадров, `Errors: []`.

Через события клавиатуры и мыши в Input System подтверждены вход по щелчку, освобождение курсора по Esc и повторный вход по щелчку, подход WASD, физический захват закрывающих коробок, подъём, вращение ПКМ, бросок и отсутствие награды за обычный мусор. E без удерживаемой находки не вызывает поиск и не создаёт награду. Металл открывается после удаления двух коробок.

Ранее передняя опорная коробка закрывала луч к металлу, а бортик закрывал луч к центру этой коробки. Добавлен удерживаемый Q: камера смещается на 0,35 м вперёд и 0,22 м вверх, с проверкой препятствий SphereCast. Игрок остаётся снаружи контейнера, коллайдеры не отключаются. С этим наклоном удалось убрать переднюю коробку, взять металл, физически поднять его выше края и положить в карман по E. Повторное E сохраняет один предмет, деньги 0, SearchCounts остаётся пустым.

Один запуск проверки был сделан в уже запущенной пользователем сцене: игрок к этому моменту подошёл к контейнеру, поэтому проверка пройденного расстояния была неприменима. После остановки и запуска из исходной позиции следующий полный прогон прошёл. Тестовая сцена и игровой сценарий не подменялись прямыми вызовами подбора.

## Самостоятельное приложение и обычный ввод

При диагностике была обнаружена запущенная старая сборка `Build/LyokhaVR-Preparation.app`, в то время как актуальная сцена редактора была остановлена. Для однозначного запуска создано отдельное приложение **LyokhaVR Container**, bundle ID `com.university.lyokhavr.container`, оконный режим 1280×800. В сборку включена только PhysicalSearchDesktop. Результат сборки — Succeeded, 0 ошибок, 1 предупреждение, 12,24 с; см. `container-build.json`.

В окне новой самостоятельной сборки через нативный ввод подтверждены Enter → захват курсора и появление прицела, W → видимое приближение к контейнеру, Esc → освобождение курсора и возврат стартовой подсказки. Кадры `native-control-active.png`, `native-walk.png`, `native-ready.png` сохранены рядом с отчётом. Координатные действия удалённого инструмента мыши вернули `noWindowsAvailable`, поэтому отдельный нативный тест мышью не заявляется; полный захват и подбор мышью проверены в редакторе через Input System. В журнале игрока нет исключений; есть предупреждения об отсутствующем символе рубля в шрифте и вырезанных неиспользуемых эффектах постобработки.

## Запуск и управление

Unity 6000.6.7f1, проект `LyokhaVR`.

Для VR-симулятора открыть `Assets/_Project/Scenes/PhysicalSearchVR.unity`, нажать Play. Используется уже импортированный официальный XR Interaction Simulator. Через его панель выбрать HMD / левый / правый контроллер; H — голова, Tab — переключение устройства, квадратные скобки — выбор руки. WASD/QE перемещают выбранное устройство, мышь/стрелки поворачивают, G — grip, T — trigger, IJKL — стик. Снять верхнюю длинную коробку, затем нижнюю коробку над золотистым металлом. Поднять металл выше бортика и нажать trigger. Для передачи поднести вторую руку, зажать её grip, затем отпустить grip первой. Для броска двигать рукой во время отпускания.

Для мыши запустить **`Build/LyokhaVR-Container.app`**, затем щёлкнуть по игре или нажать Enter. В редакторе можно открыть `Assets/_Project/Scenes/PhysicalSearchDesktop.unity` и нажать Play. WASD — движение, мышь — обзор, ЛКМ — взять/отпустить предмет под прицелом, удерживаемая ПКМ + движение мыши — осмотр, колесо — расстояние удержания, удерживаемая Q — наклон над бортиком, E — положить извлечённый металл в карман, Esc — освободить курсор. Щелчок после Esc снова включает управление и не хватает предмет в тот же момент. При потере фокуса курсор освобождается. Для извлечения убрать верхнюю длинную коробку, нижнюю коробку над металлом и переднюю опорную коробку, если она перекрывает обзор. Использовать Q для доступа к нижним предметам.

Остановить и снова включить Play для восстановления первоначальной укладки. Служебные тестовые драйверы добавляются только в Play Mode, в сценах не сохранены. Для аппаратного VR ещё нужны модель шлема, подходящий OpenXR loader/сборка и человеческая проверка удобства, досягаемости и бросков.
